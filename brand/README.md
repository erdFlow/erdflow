# erdFlow Brand

Premium developer-tool identity aligned with the app theme (indigo/violet primary).

## Assets

| File | Use |
|------|-----|
| `erdflow-logo-mark.png` | App icon, favicon, social avatar (dark) |
| `erdflow-logo-wordmark.png` | README header, docs, marketing (dark) |
| `erdflow-logo-light.png` | Light backgrounds, npm, print |

| Token | Value | Role |
|-------|-------|------|
| Primary | `#4F46E5` | Indigo — matches `--primary` |
| Accent | `#6366F1` | Lighter indigo |
| Highlight | `#8B5CF6` | Violet gradient end |
| Background (dark) | `#0F1117` | Premium charcoal |
| Foreground | `#F8FAFC` | Wordmark on dark |
